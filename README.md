# Rehan --- AI/ML Developer Portfolio

A responsive personal portfolio website showcasing Rehan's learning
journey, technical skills, selected projects, services, and contact
information.

The site is built with **HTML, CSS, and vanilla JavaScript**. It uses a
dark visual theme with gradient accents, responsive layouts, subtle
animations, and interactive project filters.

## Features

-   Responsive layout for desktop, tablet, and mobile screens
-   Navigation menu with a mobile toggle
-   Hero section with an animated role/typewriter line
-   About section and learning journey
-   Skills and tools overview
-   Filterable project cards (AI/ML, cybersecurity, web development, and
    automation)
-   Services and professional-development sections
-   Resume download link
-   Email and social contact links
-   Scroll-reveal effects, active-section navigation, and back-to-top
    button
-   Reduced-motion support and keyboard focus styles

## Built With

-   HTML5
-   CSS3
-   Vanilla JavaScript
-   Google Fonts --- Inter

## Project Structure

Keep the files and folders arranged to match the paths referenced by the
HTML:

``` text
portfolio/
├── index.html
├── README.md
└── assets/
    ├── favicon.png.png
    ├── profile.jpg.png
    └── Rehan_CV.pdf
```

If your actual filenames or folder names differ, update the
corresponding paths in `index.html`.

## Run Locally

No package installation or build process is required.

1.  Clone or download this repository.
2.  Open the project folder.
3.  Open `index.html` in your browser.

For a local development server, you can also use the **Live Server**
extension in Visual Studio Code.

## Customize the Portfolio

Before publishing, review these items in `index.html`:

1.  **Profile images:** Confirm the image paths for
    `assets/favicon.png.png` and `assets/profile.jpg.png`.
2.  **Resume:** Place your PDF in the `assets` folder and make the
    download link match its exact filename. The page currently contains
    both `assets/Rehan_CV.pdf.pdf` and `assets/Rehan_CV.pdf` references;
    make them consistent.
3.  **Contact details:** Verify the email address, GitHub profile,
    LinkedIn, Fiverr, and WhatsApp links.
4.  **Projects:** Replace sample descriptions and profile-level GitHub
    links with the correct repository or live-demo URLs. Remove any
    project that is not yet built or cannot be demonstrated.
5.  **Skills and services:** Keep only technologies and services you can
    confidently explain and deliver.
6.  **Personal information:** Review the location, biography, and
    learning-journey descriptions before making the site public.

## Deploy

You can host this static website with GitHub Pages:

1.  Push the project files to a GitHub repository.
2.  Open the repository's **Settings → Pages**.
3.  Under **Build and deployment**, choose **Deploy from a branch**.
4.  Select the branch containing your website (commonly `main`) and the
    root folder (`/`).
5.  Save the settings and wait for GitHub Pages to publish the site.

Make sure `index.html` is in the published folder and that asset paths
are correct. Your published URL will be shown in the repository's Pages
settings.
